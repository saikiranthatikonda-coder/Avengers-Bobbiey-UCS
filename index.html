WITH THE INSTALLER
  1. 01
    Run BUCS-Windows-x64-Setup.exe and follow the setup steps.
  2. 02
    If Windows SmartScreen says “Windows protected your PC”, choose More info → Run anyway. You only see this once.
  3. 03
    Open BUCS from the Start menu. The first launch takes a few minutes while it sets itself up.
WITH THE ZIP PACKAGE
  1. 01
    Install Python 3.11 or newer from python.org with “Add python.exe to PATH” ticked.
  2. 02
    Extract the ZIP, for example to Documents\BUCS.
  3. 03
    Double-click Start BUCS.cmd (SmartScreen: More info → Run anyway if shown). The first launch takes about 3–5 minutes, adds a BUCS desktop shortcut and opens BUCS in your browser.
WITH THE INSTALLER
  1. 01
    Open the .dmg for your Mac's chip and drag BUCS into Applications.
  2. 02
    Open BUCS from Applications. The first time, macOS says it can't verify the app: click Done, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. (On macOS 14 and older, Control-click BUCS → Open also works.) You only do this once.
  3. 03
    The first launch takes a few minutes while BUCS sets itself up.
WITH THE ZIP PACKAGE
  1. 01
    Install Python 3.11 or newer from python.org. The system Python 3.9 is too old.
  2. 02
    Double-click the ZIP to unzip it, and move the BUCS folder somewhere permanent, such as Documents.
  3. 03
    The first time, double-click Start BUCS.command; if macOS blocks it, go to System Settings → Privacy & Security → Open Anyway (on macOS 14 and older, Control-click → Open also works). After that, just double-click it. Setup takes about 3–5 minutes, then BUCS opens in your browser.
WITH THE APPIMAGE
  1. 01
    Make it executable: chmod +x BUCS-Linux-x64.AppImage (or Properties → Permissions → Allow executing as program).
  2. 02
    Run it: ./BUCS-Linux-x64.AppImage. If it reports missing FUSE, install your distro's libfuse2 package, or run it with --appimage-extract-and-run.
  3. 03
    The first launch takes a few minutes while BUCS sets itself up.
WITH THE ZIP PACKAGE
  1. 01
    Check python3 --version shows 3.11 or newer; if not, install it from your package manager.
  2. 02
    Unzip it: unzip bucs-latest.zip, then cd BUCS.
  3. 03
    Run bash start-jarvis.sh. Setup takes about 3–5 minutes, then BUCS opens in your browser.
ACTIVATE
  1. Copy your install ID from the activation screen. It looks like 1A2B3-C4D5E.
  2. Pay below with any UPI app and send the UTR + install ID.
  3. Your key arrives by email: paste it and press ACTIVATE.
UNINSTALL
  • Windows installer: Settings → Apps → Installed apps → BUCS → Uninstall.
  • macOS app: quit BUCS, then drag it from Applications to the Bin.
  • Linux AppImage: quit BUCS and delete the .AppImage file.
  • ZIP package: delete the BUCS folder. Your settings and licence live inside it, so copy them out first if you plan to come back.
