REQUIREMENTS
Windows 10 / 11 · 8 GB RAM · internet for the first setup
Python 3.11+: tick “Add python.exe to PATH” when installing
Optional: Ollama for fully local AI · a webcam and mic for vision and voice
  1. 01
    Install Python 3.11 or newer from python.org, with “Add python.exe to PATH” ticked.
  2. 02
    Download BUCS and extract the ZIP, for example to Documents\BUCS.
  3. 03
    Double-click Start BUCS.cmd. The first launch sets everything up (about 3–5 minutes), adds a BUCS shortcut to your desktop, and opens BUCS in your browser.
  4. 04
    Copy your install ID from the activation screen. It looks like 1A2B3-C4D5E.
  5. 05
    Pay below with any UPI app and send the UTR + install ID. Your key arrives by email: paste it, press ACTIVATE, done.
